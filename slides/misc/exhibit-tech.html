前端架構與 UI 實現

  • React 18 + TypeScript
    嚴謹的型別系統，確保資料流與狀態管理的穩定性
  • Tailwind CSS + Glassmorphism
    高度客製化的毛玻璃特效，打造現代化且通透的視覺體驗
  • Responsive Design (RWD)
    從手機到桌面端，提供一致流暢的多維度篩選介面

AI 與資料層

  • 資料彙總與清洗
    從多個不規則的展覽資料源爬取原始資訊並標準化
  • AI 智慧分類引擎
    透過大語言模型對展覽內容進行自然語言理解與自動標籤化
  • 多維度動態篩選
    支援地區、類別、時間的複合式查詢，瞬間定位目標展覽
