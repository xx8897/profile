HOMELAB AI STACK

為什麼要自建本地 AI 叢集？

雲端 API 方便，但成本不可控、資料外洩風險高 —— 我決定用消費級硬體打造自己的 AI 推理環境

🚨 痛點
  • 雲端 API 月費快速累積，日常使用成本不可控
  • 對話資料傳送海外，企業場景下隱私與合規風險高
  • 依賴單一雲端供應商，服務中斷即業務停擺
  • 缺乏端到端監控，無法掌握推理延遲與資源使用狀況
🎯 目標
  • 日常 AI 使用零 API 費用、零資料外洩
  • 建構 Supervisor-Worker 分層架構，大模型做規劃、小模型做執行
  • 實現全棧 MLOps 監控：任何節點異常立即告警
  • 撰寫完整 ADR 與維運手冊，確保系統可追溯、可維護
🧩 設計哲學：大學長帶高中生
不把所有推理都塞到最強的模型上。而是讓35B 大模型（Mac M4）負責策略規劃與審核，讓4B 小模型（RTX 3070）處理格式化執行與摘要。Worker 失敗時 Supervisor 親自下場，而非切換到其他小模型。
