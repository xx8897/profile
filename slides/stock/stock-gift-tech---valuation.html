🧮 核心估值公式
CP 值 =
五年總估值 ÷ 最近股價
×
發放次數 ÷ 5
五年總估值：對近五年發放的紀念品，逐一用知識樹引擎估算市場價值後加總
最近股價：透過 FinMind API 自動抓取，每週三次 GitHub Actions 定時更新
發放次數 ÷ 5：衡量穩定性，五年皆發放則係數為 1，僅一年發放則為 0.2
