LiteLLM Proxy：多模型負載均衡

統一 API 介面，管理多個本地與雲端模型的負載均衡、容錯路由與 API Key 管理

🔗 LiteLLM 核心優勢
  • 統一 API 介面：無論後端是 Ollama、vLLM 還是 OpenAI，前端統一調用 OpenAI 格式，達成「無感切換」。
  • API Key 集中管理：透過單一入口管理所有模型的存取權限與配額，簡化前端邏輯。
🛡 階層式 Fallback 路由機制

確保 AI 服務的高可用性，當本地硬體負載過高或異常時自動導流：

  • L1 (本地主力)：優先發送至 Mac M4 運算中樞，享受極低延遲。
  • L2 (本地輔助)：若 L1 忙碌或斷線，自動降級至本地其他運算節點 (Local Workers)。
  • L3 (雲端備援)：極端情況下，自動路由至雲端 API (如 GPT-4o-mini)，保證服務 100% 在線。
