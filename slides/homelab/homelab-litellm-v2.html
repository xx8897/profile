HOMELAB AI STACK — LITELLM

LiteLLM Proxy：多模型負載均衡

統一 API 介面，管理多個本地與雲端模型的負載均衡、容錯路由與 API Key 管理

🚧 強大的 AI Gateway 核心
  • 多設備負載均衡 (Load Balancing)：自動在 Mac M4 中樞與多台本地 Worker 之間分配算力請求，極大化硬體利用率。
  • 統一 OpenAI API 協定：將異質後端（Ollama, vLLM）封裝為標準 OpenAI API，讓所有 AI 應用程式能無縫對接。
  • 流量治理與監控：內建計費與流量限制 (Rate Limiting)，並與 Grafana 整合實現即時的 API 調用監控。
🛡 階層式 Fallback 與高可用路由

形成一套永不斷線的算力保險機制：

  • L1 (本地主力)：極速推理，由 Mac M4 主機承擔 90% 以上請求。
  • L2 (異地負載)：當主機過載時，自動溢流至本地其他 Linux / PC 算力節點。
  • L3 (彈性雲端)：本地全數不可用時，自動切換至 OpenAI / Groq 等雲端 API 備援。
